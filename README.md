# Confidentialité — SOIPP

Les politiques de confidentialité des extensions et plugins SOIPP, réunies en un seul endroit.

**[Consulter le site](https://soipp.github.io/privacy-policies/)**

Chaque politique concerne un produit précis et présente ses pratiques relatives aux données : informations traitées, finalités, destinataires, conservation et moyens de contact.

Les politiques sont ajoutées au fil de leur publication. Pour connaître les informations applicables à un produit, consultez sa page dédiée.
